# Employee Workforce Analysis | SQL Project

## About the Project

This project focuses on analyzing employee workforce data using MySQL. The goal is to explore employee information, salary trends, department distribution, job titles, and hiring patterns using SQL queries.

Through this project, I practiced SQL concepts and developed my data analysis and problem-solving skills.

## Tools Used
- MySQL
- MySQL Workbench

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- JOINs
- Subqueries
- Date Functions

## Dataset

The Employees dataset used in this project was provided by our instructor for learning and SQL practice.

The complete database file is not included in this GitHub repository because of its large size. This repository contains the SQL queries used to perform the analysis.

**Reference link:** [MySQL Employees Sample Database](https://github.com/datacharmer/test_db)

To reproduce the analysis, you will need access to the database and must import it into MySQL before running the queries.

## Key Analysis Areas
- Employee demographics and hiring trends
- Department-wise employee counts
- Average salary analysis
- Job title distribution
- Employee workforce insights
